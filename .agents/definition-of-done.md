# 完成标准

任务只有在实现、验证和交付信息都闭环后才算完成。

## 实现完成

- 已满足用户明确需求，未引入需求外行为变化。
- 已检查空值、失败、取消、重复执行、并发及资源清理路径。
- 涉及共享模块时已搜索全部调用方并确认兼容。
- 涉及异步操作时 UI 有明确 loading、成功与失败反馈，且不会重复触发或永久卡住。
- 涉及跨平台能力时已检查 macOS 与 Windows 分支。

## 验证完成

- 优先运行本次改动对应的最小测试集，并记录结果。
- 代码改动完成后至少运行 `pnpm run lint`、`pnpm run typecheck` 和相关 Vitest 测试；无法运行时说明具体原因。
- 修改 UI 构建、入口、类型或依赖时运行 `pnpm run build:ui`。
- 修改 Electron 启动、preload、IPC 注册或主窗口时运行 `pnpm run verify:boot`。
- 修改发布与打包链路时运行对应静态测试，并在条件允许时执行目标平台打包验证。
- 不以历史测试失败掩盖新增回归；若遇到与本次无关的既有失败，要区分并如实报告。

## 交付完成

- 最终说明包含改了什么、关键原因以及实际运行的验证命令与结果。
- 明确列出未验证项、残余风险或需要用户完成的外部步骤。
- 不声称未执行的测试、构建、发布或人工检查已经通过。
- 除非用户明确要求，不自动提交、推送、创建 PR、打 tag 或发布 Release。
